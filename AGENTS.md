# AGENTS.md — thaifont

## What this is
A Thai font designed to highlight vowels from consonants, making it easier to learn and read Thai script by visually distinguishing vowel sounds within words.

## Stack
- OpenType font (.otf)
- Static HTML/CSS demo site
- GPLv3 licensed

## Run
- Open `pages/public/index.html` in a browser or visit https://thaifont.myridia.com/
- Use the font in any HTML page via `@font-face` with `Myridia-Normal.otf`

- `*.otf` — font files (Myridia-Normal)
